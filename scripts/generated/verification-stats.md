## Counting rules

- **Files**: every `.lean` file under `lean/Evm`, `lean/*.lean`, `verify/velvet-slots` and `verify/protocols` (no `.lake`); each belongs to exactly one component (first matching path pattern; an unclaimed file fails the generator).
- **Lines**: physical lines after removing comments (`--`, `/- -/`, docstrings) and blank lines; each line counted once.
- **Declarations**: a declaration starts at a column-0 command keyword (attributes and modifiers allowed) and runs to the next one; column-0 continuations (`|` arms, `where`, `termination_by`, `deriving`) stay with it.
- **Theorem statement lines**: `theorem`/`lemma` from the keyword to the line holding the first `:=` outside brackets (a `let`/`have` inside the statement skipped), or to the line before a leading `|` arm; a line shared with the proof counts here.
- **Proof lines**: the rest of a theorem; a Velvet `prove_correct` block entirely; `example` blocks split like theorems.
- **Definition lines**: `def`, `abbrev`, `structure`, `inductive`, `instance`, `class`, `opaque`, `axiom`, macros and notation, Velvet `method`, and in `verify/protocols` the Veil model text (`veil module`, `action`, `invariant`, `safety`, ...).
- **Statement lines**: definition lines + theorem statement lines: the statements and the definitions they rely on.
- **Other lines**: `import`, `namespace`/`section`/`end`, `open`, `variable`, `set_option`, `attribute`, `#` commands: in neither column.
- **Theorems**: `theorem`/`lemma` declarations plus Velvet `prove_correct` blocks; `example` blocks are not counted.
- **Totals**: the claim rows only; the tools row (`lean/*.lean` executables) is listed but not totalled.
- **sorry**: `\bsorry\b` in the comment-stripped text (the coverage matrix's rule).
- **native_decide**: occurrences in the comment-stripped text.
- **Axioms**: `lean/Evm` theorems: their closures in `scripts/generated/axiom-audit.txt` (`scripts/verify-axioms.sh`); standard = only `propext`, `Classical.choice`, `Quot.sound`; with `native_decide` = the closure has a `._native.native_decide` auxiliary axiom. `verify/velvet-slots`: the `#print axioms` of `Slots/Axioms.lean`, which `verify-velvet-slots.sh` requires to be standard. `verify/protocols`: the axiom checks `verify-protocols.sh` requires to be standard.
